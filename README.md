# بنك أسئلة تمييز الأنماط

موقع HTML ساكن وتفاعلي باللغة العربية، مبني من الملف الأصلي المرفق. يتضمن:

- 144 سؤالًا موزعة على المحاضرات 1 و3 و4 و6 و7 و8.
- وضع تدريب بتصحيح فوري ووضع اختبار بتصحيح عند عرض النتيجة.
- تصفية حسب نوع السؤال ومراجعة الأخطاء.
- حفظ تلقائي للتقدم في `localStorage` داخل المتصفح.
- تصميم متجاوب للكمبيوتر والجوال وبدون اعتماد على الإنترنت.

## التشغيل محليًا

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173` داخل هذا المجلد.

## النشر على GitHub Pages

ارفع `index.html` إلى مستودع GitHub، ثم فعّل GitHub Pages من إعدادات المستودع باستخدام الفرع الرئيسي ومجلد الجذر.
